# Mines Strategy Simulator

An **educational Mines-style strategy simulator** built with **Python** and **Tkinter**.  
This project focuses on **probability, risk management, and decision-making**, not real gambling.

---

## Disclaimer

**Educational / simulation only.**  
- No real money  
- No gambling  
- No monetization  

This project exists strictly for **learning, demonstrations, and portfolio use**.

---

## Game Objective

- Start with a balance based on difficulty
- Place bets and reveal tiles while avoiding mines
- Apply strategy and probability to grow your balance
- **Goal:** Reach **$10,000**
- If your balance reaches **$0**, the run ends

---

## Difficulty Levels

| Difficulty | Starting Balance | Ballot Entries |
|----------|------------------|----------------|
| Easy     | $1000            | 1 entry       |
| Medium   | $500             | 3 entries     |
| Hard    | $100             | 6 entries     |

> Hard mode is more challenging but gives **better odds** in the ballot system.

---

## Reward & Entry System (Educational Raffle)

- Reaching the goal awards a **unique code**
- Each difficulty grants a different number of **entries**
- Entries determine how many times your name is placed into the ballot
- A **random ballot winner** receives the reward (e.g., $15 Gift Card of Choice)

You may:
- Continue playing after reaching the goal
- Claim your reward anytime using the **“Claim Reward”** button
- Claiming ends the current run and provides your code and instructions

---

## Code Submission

When claiming a reward, you will receive:
1. A **unique code**
2. Instructions to submit:
   - Your **email**
   - The **generated code**
   - The **difficulty completed**

Submission is done through the Google Form link displayed in-game.

---

## Features

- Tkinter-based GUI
- Strategy-focused Mines gameplay
- Adjustable mine count between rounds
- Probability-based multipliers
- Multiple difficulty modes
- One code per run (no duplicates)
- Friendly reminders (no nagging popups)
- Built-in educational disclaimers
